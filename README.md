# Recetas fit

Recetario personal con mucha proteína y poca grasa: filtros, plan semanal, lista de la compra, modo cocina con temporizadores y guía de qué marca comprar.

Web: https://hectorgarvi.github.io/recetario-fit/

Los datos personales (favoritas, notas, plan, lista de la compra y fotos) no están en este repositorio. Se guardan en el navegador y, si se conecta un token, en un repositorio privado aparte.

Los valores nutricionales son aproximados.
